# Hadir | حاضر

موقع عربي RTL لوكالة تصميم مواقع مع لوحة إدارة وخادم Node.js وقاعدة SQLite. لا توجد حزم خارجية مطلوبة؛ يتطلب Node.js 22.5 أو أحدث لأن SQLite مدمجة في Node.

## بنية المشروع

```text
server.js                  خادم HTTP وواجهات API
package.json               أوامر التشغيل والاختبار
start.bat                  تشغيل سريع على Windows
.gitignore
README.md                  دليل المشروع
tests/integration.test.js  اختبارات التكامل
data/                       قاعدة SQLite (تُنشأ تلقائياً)
public/index.html           الموقع العام
public/admin.html           لوحة الإدارة
public/css/site.css         تنسيقات الموقع
public/css/admin.css        تنسيقات لوحة الإدارة
public/js/app.js            ربط الموقع بالـ API
public/js/admin.js          تطبيق لوحة الإدارة
```

## التشغيل المحلي

تأكد أن إصدار Node.js هو 22.5 أو أحدث (`node --version`). افتح مجلد المشروع في PowerShell أو CMD ونفّذ:

```powershell
npm start
```

افتح الموقع على http://localhost:8000/ ولوحة الإدارة على http://localhost:8000/admin.html. أوقف الخادم بـ `Ctrl+C`. لتغيير المنفذ: `$env:PORT=8080; npm start`.

يمكن تشغيل `start.bat` بالنقر المزدوج. لا تشغّل نسختين على المنفذ نفسه.

## إعداد حساب المدير

في أول زيارة إلى `/admin.html` ستظهر شاشة إعداد حساب المدير. اختر اسم مستخدم من 3 إلى 40 حرفاً وكلمة مرور من 12 حرفاً على الأقل. لا توجد كلمات مرور افتراضية. كلمات المرور مخزنة بـ scrypt مع salt عشوائي، والجلسة Cookie من نوع HttpOnly وSameSite Strict لمدة 7 أيام. تتوفر من الإعدادات إمكانية تغيير كلمة المرور مع التحقق من الحالية.

## قاعدة البيانات والنسخ الاحتياطي

تُنشأ قاعدة البيانات تلقائياً في `data/hadir.sqlite`، وتشمل المدير والإعدادات والخدمات والأعمال ورسائل التواصل. تُزرع الخدمات والأعمال والإعدادات الافتراضية فقط، ولا توجد رسائل وهمية. كل رسائل الزوار تصل إلى قاعدة الخادم نفسها.

من لوحة الإدارة > الإعدادات، أنشئ نسخة احتياطية SQLite متسقة ونزّلها. يحفظ الخادم آخر 10 نسخ تحت `data/backups/`؛ نزّل النسخة إلى مكان آمن خارج الخادم بانتظام. لا تعتمد على النسخة الوحيدة الموجودة على الخادم.

## الاختبار

```powershell
npm test
```

تشغّل الاختبارات على قاعدة مؤقتة منفصلة وتختبر إعداد المدير، تسجيل الدخول، الرسائل، صلاحيات الإدارة، وعمليات CRUD.

## واجهات API

- `GET /api/health` فحص الخادم وقاعدة البيانات.
- `GET /api/setup/status` التحقق من إعداد المدير الأول.
- `GET /api/public` جلب إعدادات الموقع والخدمات والأعمال.
- `POST /api/messages` حفظ نموذج التواصل.
- `POST /api/setup` إنشاء المدير الأول مرة واحدة.
- `/api/auth/*` تسجيل الدخول والخروج والتحقق من الجلسة.
- `/api/admin/*` عمليات إدارة محمية بالجلسة، وتشمل إدارة الرسائل والمحتوى والصور والنسخ الاحتياطية. صور الأعمال المرفوعة محفوظة في `public/uploads/`؛ ضمّ هذا المجلد إلى خطة النسخ والنشر.

## النشر العام

1. استخدم استضافة Node.js أو VPS مع قرص دائم، وفعّل HTTPS.
2. أنشئ مفتاحاً مؤقتاً لإعداد أول مدير في PowerShell: `$env:HADIR_SETUP_SECRET = [guid]::NewGuid().ToString('N')`.
3. شغّل الخادم بهذا المتغير، وأدخل المفتاح في شاشة الإعداد. بعد إنشاء المدير أوقف الخادم وأزل المفتاح من بيئته؛ لا تضعه في ملفات الواجهة أو Git أو سجلات التشغيل.
4. عيّن `HOST=0.0.0.0` عند الحاجة. يرفض الخادم الاستماع على واجهة عامة إذا لم يوجد مدير ولم يُحدّد مفتاح الإعداد.
5. مع `NODE_ENV=production` تصبح Cookie الجلسة Secure؛ HTTPS مطلوب، ويضيف الخادم HSTS.
6. لا تُضمّن مفاتيح API أو كلمات مرور أو أسراراً في HTML أو JavaScript أو مستودع Git. عند إضافة تكامل خارجي لاحقاً، خزّن سره في متغير بيئة على الخادم فقط، واستخدم مخزن أسرار منصة النشر لـ CI/CD. دوّر فوراً أي سر تم كشفه.
7. الطلبات المعدّلة للبيانات ترفض Origin المختلف، ويصدر الخادم رؤوس حماية منها `X-Frame-Options: DENY` و`nosniff`. هذه إجراءات تخفيف للمخاطر وليست بديلاً عن HTTPS والتحديثات وإدارة الأسرار.
8. احتفظ بمجلد `data/` على تخزين دائم ولا تضعه ضمن الملفات العامة أو المستودع. SQLite مناسبة لنسخة واحدة؛ عند التوسع لعدة نسخ استخدم PostgreSQL.

## ملاحظات

- بيانات الهاتف والبريد والعنوان فارغة في قاعدة البيانات الأولية، ولا تظهر كجهات اتصال إلا بعد ضبطها من إعدادات لوحة الإدارة. أُزيلت قيم الاتصال المثال القديمة عند بدء الخادم.
- الأعمال المعروضة تصورات توضيحية وليست أعمال عملاء موثقة. صورها من Unsplash وتحتاج اتصال إنترنت.
- تُصحح أوصاف الخدمات الافتراضية القديمة عند بدء الخادم لتجنب ضمانات غير موثقة، مع الحفاظ على محتوى الخدمات الذي تعدله من لوحة الإدارة.
- يمكن البحث في الرسائل وتصفيتها بالتاريخ والحالة، وترتيب الخدمات ونماذج الأعمال. رفع الصور يدعم PNG/JPG/WebP/GIF حتى 4 MB مع فحص ترويسة الملف.
- المصدر الفعّال للواجهة موجود في `public/`؛ الملفات القديمة خارج هذا المجلد لا تُستخدم.
